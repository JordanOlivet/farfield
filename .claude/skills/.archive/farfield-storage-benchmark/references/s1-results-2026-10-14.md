# Spike S1 storage results (2026-10-14)

Smoke run: `amplified` world, 3 regions (39.5 MB), 3,072 full chunks, 14 threads.

| Encoder (all levels) | MB | bytes/full chunk | vs region files |
|---|---|---|---|
| dense+zstd3 (Voxy-style, 64-bit per voxel) | 34.3 | 11,162 | 86.8% |
| codec raw | 157.8 | 51,366 | 399.2% |
| codec+zstd3 | 20.9 | 6,810 | 52.9% |
| codec+zstd9 | 18.3 | 5,962 | 46.3% |
| codec+zstd3+dict | 21.8 | 7,106 | 55.2% |
| no light+zstd3 | 17.2 | 5,591 | 43.5% |
| face light+zstd3 | 20.3 | 6,599 | 51.3% |
| hidden+face, codec | 14.1 | 4,603 | 35.8% |
| hidden+face, byte-indexed | 14.4 | 4,682 | 36.4% |
| hidden+face, byte + up filter | 16.4 | 5,339 | 41.5% |

Findings:
- Light weighs about 18% of bytes. Keeping light only on drawn faces costs little.
- Hidden voxels (opaque, all six neighbors opaque) removed: about 33% smaller than codec+zstd3. Border voxels kept.
- Up-filter and trained dictionary made it worse on this data. Dictionary training is not a win here.
- Level 0 dominates: codec+zstd3+dict 17.7 MB of 21.8 MB total.
- Brick dedup after fix: 18.5% of non-uniform block bricks duplicate (was 2.3% before the aliasing fix, see benchmark-variant-hygiene).
- Read path, one thread, 403 level-0 sections: dense+zstd 59.7 us, codec+zstd+dict 39.7 us.

Containers (smoke, 5,526 records, 21.9 MB payload):
- LogStore: 181 MB/s write, 0.9% overhead, random read 137,829 rec/s (1 thread), 206,087 rec/s (8 threads).
- LMDB: 74 MB/s write, 45% overhead, random read 186,865 rec/s (1 thread), 1,193,108 rec/s (8 threads).
- Crash test (2 kills each): both containers recovered every durable record, 0 torn-tail bytes cut.
