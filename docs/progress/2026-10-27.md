## What was done

The user (2026-10-26): "Fais le point 1 et 4 maintenant. On fera la
release une fois que toutes les fonctionnalités actuelles seront
complètes", and "Ne t'occupe pas de voxy". Work started on 2026-10-26 in
the evening and was checked today. ADR-070.

- **Other protocol versions declined.** A server answers a hello of
  another version with a refusal: a welcome of session -1 carrying its
  own version (`Welcome.declined`); it reads only the hello's first field,
  so another hello shape does not matter. The client logs both versions
  and builds its own LODs. A client also builds its own LODs after 6
  hellos without an answer (60 s), for servers from before this change.
  Before, such a client waited forever and drew nothing.
- **The server's ids translated on receipt.** The mirror's key tables are
  its own again: `KeyTranslation` keeps the server's keys in id order
  beside the mirror (`server-block-states.txt`, `server-biomes.txt`) with
  the mirror's id of each. A writer thread (`farfield-stream-mirror`)
  decodes each received section, remaps its palette and biomes
  (`LodSection.remapIds`) and stores it (`LodWorld.putSection`), or stores
  the record as it came when no id changes; tiles likewise
  (`PreviewTile.remapIds`, `PreviewStore.decodeFile`). A section or tile
  the writer could not store is fetched again. The frozen tables are gone
  (`KeyRegistry.freeze`, `idForced`, `find`; `MaterialTable`'s fall-backs
  to the bare ground): the preview's covered materials get their key on a
  streamed client, so the speckle can come back on coarse levels. A
  mirror from before (tables equal to the server's, no key files) keeps
  its tables as the server's keys: no refetch.
- **Fix:** a tile's file could not replace the old one on Windows while a
  preview thread read it (`AccessDeniedException` on the move, seen once
  in the first run; the tile was fetched again). `PreviewStore` now tries
  the move again for a moment.
- Stat line: `translated` sections; the mirror's close line counts the
  server's keys and its own.
- Core tests: `KeyTranslation` (keys held again, a gap, a disagreement),
  a section translated into a mirror with a key of its own,
  `PreviewTile.remapIds`, `decodeFile` on bad files, the refusal's shape.
