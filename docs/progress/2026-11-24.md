### Done

- **Streaming across loaders.** A Fabric client on a Forge server got no
  answer (`Received invalid discriminator byte 33 on channel
  farfield:stream`): Forge's `SimpleChannel` puts a discriminator byte
  before the payload. The Forge side is now a raw channel
  (`EventNetworkChannel`) carrying Fabric's bytes. The handshake accepts
  any version of the other side; the stream protocol's hello declines
  another version, as ADR-070 decided (no new decision). The other way, a
  Forge client on a Fabric server built its own LODs: Forge 47 keeps only
  the channel names followed by a zero byte, and Fabric ends its
  `minecraft:register` list without one, so Farfield's channel, last of
  the list, was dropped. `ClientPacketListenerMixin` (forge project) reads
  the list beside Forge.
- **Sodium 0.5 and Embeddium 0.3 (plan S.3).** No mixin of ours is needed:
  the Sodium 0.8 one is an optional shortcut and its plugin leaves it out.
  The hand-off rule was wrong on the rim: Sodium 0.5.13 and Embeddium
  0.3.31 test a section's distance on its own box (read in both jars),
  Sodium 0.8.13 grows it by one block. The LODs hid their water where
  Embeddium drew nothing: dark pits over the sea at the far edge of the
  game's view. `u_sodiumGrow` (0 for the `me.jellysquid` Sodium, 1
  otherwise), and the log says which.
- **Shader packs (plan S.1, S.2).** The nine Iris targets, read in Iris
  1.7.6 and in Oculus 1.8.0: eight are the same as in Iris 1.8. The ninth,
  `ShaderPack`'s constructor in `Iris.loadExternalShaderpack`, has no "is a
  zip" flag there, so the contract macro was never added and the renderer
  said `LOD rendering off under shader pack ...: the pack was loaded
  without a LOD contract's macro`. A second optional injection takes the
  older call. On Forge the renderer also looked for the mod `iris`: Oculus
  has Iris's classes under the id `oculus`.
- **Tools.** `dev/rehearsal/prod-client.sh` starts a production client
  (launcher layout, shipped jars) through portablemc with an offline name,
  installs kept in `runs/pmc` (gitignored, 0.8 GB), and runs a Rehearsal
  command file in it; `dev/rehearsal/fetch-mods.py` downloads test mods
  from Modrinth, each checked against its sha512. Rehearsal's own scripts
  use portablemc the same way for NeoForge packs.
